# Dashboard Operacional

## 1. Para que serve

O Dashboard oferece uma visao rapida da operacao do estabelecimento.

Ele ajuda a responder perguntas do dia a dia:

- Existem pendencias importantes?
- Quais sao os proximos atendimentos?
- Como esta a agenda de hoje?
- Quantos atendimentos estao confirmados, concluidos ou cancelados?
- Existem clientes aguardando atendimento?
- Como esta a ocupacao da agenda?
- Existem erros ou pendencias de WhatsApp?
- Quais servicos tiveram maior movimento?
- Quais profissionais estao mais ocupados?
- O que aconteceu recentemente na operacao?

O objetivo e permitir que o usuario comece o dia pelas informacoes mais importantes, sem precisar abrir varias telas.

## 2. Como interpretar a tela

A tela esta organizada por prioridade operacional.

No topo ficam o nome do estabelecimento, o usuario logado, a busca em breve, notificacoes, perfil e saida. Logo abaixo aparece o resumo do estabelecimento, com o plano atual e os dias restantes de trial quando essa informacao estiver disponivel.

Em seguida, a tela mostra pendencias, atalhos, agenda, indicadores e historico recente.

No celular, os cards aparecem em sequencia vertical. A ordem continua priorizando primeiro os pontos que podem exigir acao.

## 3. Cabecalho

| Informacao | O que significa |
| --- | --- |
| Nome do estabelecimento | Identifica qual operacao esta sendo acompanhada. |
| Painel do salao | Indica que o usuario esta na visao principal da operacao. |
| Busca em desenvolvimento | Campo desabilitado que indica uma funcionalidade futura. |
| Notificacoes | Acesso visual para avisos do sistema. |
| Perfil | Acesso aos dados do usuario. |
| Sair | Encerra a sessao e retorna para a tela de entrada. |
| Plano atual | Mostra o plano contratado ou plano inicial. |
| Dias de trial restantes | Mostra quanto tempo resta do periodo de teste, quando aplicavel. |

Ao visualizar essa area, o usuario deve confirmar se esta no estabelecimento correto e se o plano esta em situacao esperada.

## 4. Pendencias importantes

O card **Pendencias importantes** mostra situacoes que podem exigir atencao para a operacao seguir sem travar.

Podem aparecer alertas de agenda, clientes, WhatsApp, servicos, profissionais, assinatura ou campanhas, conforme o que estiver acontecendo.

As prioridades podem aparecer como:

| Prioridade | Como interpretar |
| --- | --- |
| Critica | Exige atencao rapida, pois pode impactar atendimentos, comunicacao ou continuidade da operacao. |
| Atencao | Deve ser acompanhada para evitar atrasos ou falhas. |
| Informacao | Ajuda o usuario a entender algo relevante, mas sem urgencia imediata. |

Quando aparece **Tudo em ordem**, significa que nao ha pendencia importante no momento.

Quando o alerta for clicavel, ele leva para a area relacionada, como Agenda, Clientes, Campanhas ou Configuracoes.

## 5. Acoes rapidas

O card **Acoes rapidas** reune atalhos para as operacoes mais frequentes.

| Acao | Quando usar | Para onde leva |
| --- | --- | --- |
| Novo agendamento | Quando o usuario precisa registrar um novo atendimento. | Tela de novo agendamento. |
| Novo cliente | Quando o usuario precisa cadastrar um cliente. | Tela de clientes, iniciando cadastro. |
| Novo servico | Quando o usuario precisa cadastrar ou revisar servicos. | Tela de servicos. |
| Nova campanha | Quando o usuario precisa criar ou acompanhar comunicacoes/campanhas. | Tela de campanhas. |

Essas acoes podem variar conforme as permissoes do usuario. Usuarios com acesso mais restrito podem ver menos atalhos.

## 6. Proximos atendimentos

O card **Proximos atendimentos** mostra os horarios mais proximos para acompanhamento imediato.

Ele exibe atendimentos futuros, priorizando os que estao mais perto de acontecer. Cada item mostra cliente, servico, horario/data e profissional.

Quando nao ha atendimentos confirmados, aparece:

**Nenhum atendimento confirmado**
**Assim que a agenda for ativada, os proximos horarios aparecem aqui.**

Quando disponivel, o botao **Novo agendamento** indica que o usuario pode criar um novo atendimento.

## 7. Agenda do dia

O card **Agenda do dia** mostra os atendimentos de hoje, priorizando os proximos horarios.

Cada atendimento pode exibir:

| Informacao | O que significa |
| --- | --- |
| Horario | Hora prevista do atendimento. |
| Cliente | Pessoa agendada. |
| Servico | Servico marcado. |
| Status | Situacao atual do atendimento. |

Os horarios futuros aparecem antes dos horarios ja passados. Atendimentos ja passados ficam depois, ajudando o usuario a focar no que ainda precisa acompanhar.

Quando nao ha itens, aparece:

**Agenda pronta para operar**
**Quando os primeiros horarios forem criados, a visao do dia aparece aqui.**

Status exibidos em linguagem amigavel:

| Status | Como interpretar |
| --- | --- |
| Solicitado | O atendimento foi solicitado. |
| Aguardando confirmacao | A confirmacao ainda esta pendente. |
| Aguardando confirmação do estabelecimento | O estabelecimento ainda precisa confirmar. |
| Aguardando confirmação do cliente | O cliente ainda precisa confirmar. |
| Confirmado | O atendimento esta confirmado. |
| Concluido | O atendimento foi finalizado. |
| Cancelado | O atendimento foi cancelado. |
| Cliente não compareceu | O cliente não compareceu. |
| Reagendado | O atendimento foi remarcado. |
| Revisao necessaria | Existe uma situacao que precisa ser revisada. |

## 8. Indicadores resumidos

Logo abaixo da agenda aparecem indicadores rapidos. Eles podem variar conforme o perfil do usuario.

| Indicador | O que mede | Periodo | Como interpretar |
| --- | --- | --- | --- |
| Faturamento previsto hoje | Soma dos valores de atendimentos confirmados ou concluidos. | Hoje | Ajuda a acompanhar a previsao de receita do dia. |
| Clientes ativos | Clientes ativos vinculados ao estabelecimento. | Base atual | Mostra o tamanho da base ativa. |
| Capacidade ocupada hoje | Atendimentos nao cancelados em relacao a uma capacidade diaria estimada. | Hoje | Ajuda a entender se ainda ha espaco para novos atendimentos. |
| Agenda ativa hoje | Agendamentos de hoje que nao estao cancelados. | Hoje | Mostra o volume operacional do dia. |
| Agenda vinculada ou Agenda propria | Atendimentos do profissional vinculado ao usuario. | Hoje | Usado quando o acesso e limitado ao proprio contexto profissional. |
| Clientes proprios | Clientes relacionados aos atendimentos do profissional. | Base do profissional | Ajuda o profissional a acompanhar sua carteira. |
| Ganhos, Ganhos proprios ou Comissao | Valores dos atendimentos confirmados ou concluidos do profissional. | Hoje | Ajuda no acompanhamento individual. |
| Horarios | Janelas de agenda configuradas para o profissional. | Configuracao atual | Indica se ha horarios de trabalho cadastrados. |
| Servicos executados | Servicos liberados para o profissional. | Catalogo atual | Mostra quantos servicos o profissional pode executar. |

## 9. Visao operacional

O bloco **Visao operacional** mostra prioridades do ciclo de atendimento de hoje.

| Indicador | O que significa | Como interpretar | Quando exige atencao |
| --- | --- | --- | --- |
| Agendamentos do dia | Todos os agendamentos de hoje, incluindo cancelados e clientes que não compareceram. | Mostra o volume total do dia. | Quando o volume estiver fora do esperado. |
| Aguardando estabelecimento | Atendimentos pendentes de confirmação do estabelecimento ou em revisão. | Mostra o que ainda precisa de resposta operacional. | Quando for maior que zero. |
| Em andamento agora | Atendimentos confirmados ou aguardando cliente cujo horario atual esta entre inicio e fim. | Mostra o que deveria estar acontecendo agora. | Quando houver atendimento aberto que precisa ser acompanhado. |
| Concluidos hoje | Atendimentos finalizados no dia. | Mostra o que ja foi encerrado. | Quando estiver baixo perto do fim do expediente. |
| Cancelados hoje | Atendimentos cancelados no dia. | Mostra perdas ou mudancas na agenda. | Quando crescer acima do normal. |
| Clientes que não compareceram hoje | Atendimentos em que o cliente não compareceu. | Mostra faltas registradas. | Quando for maior que zero ou recorrente. |
| Taxa de comparecimento | Percentual de concluídos em relação aos concluídos + clientes que não compareceram. | Quanto maior, melhor o comparecimento. | Quando cair ou ficar abaixo do esperado. |
| Ocupacao da agenda | Atendimentos nao cancelados em relacao a capacidade diaria estimada. | Mostra quanto da agenda esta ocupada. | Muito baixa pode indicar espaco para novos agendamentos; muito alta pode exigir cuidado com encaixes. |

## 10. Clientes e Agenda

O bloco **Clientes e agenda** mostra sinais do ciclo operacional atual.

| Indicador | O que significa | Periodo |
| --- | --- | --- |
| Clientes atendidos hoje | Clientes diferentes com atendimento concluido. | Hoje |
| Clientes novos no mes | Clientes diferentes encontrados no historico operacional do mes. | Mes atual |
| Clientes recorrentes no mes | Clientes com mais de um registro no historico operacional. | Mes atual |
| Status da agenda | Quantidade de agendamentos por situacao. | Mes atual |

Na lista **Status da agenda**, a tela exibe situações em linguagem funcional, como aguardando confirmação do cliente, aguardando confirmação do estabelecimento, concluído, cancelado, cliente não compareceu, confirmado ou revisão necessária.

## 11. WhatsApp operacional

O bloco **WhatsApp operacional** acompanha as comunicacoes operacionais geradas pelo sistema.

| Indicador | O que significa | Periodo |
| --- | --- | --- |
| Mensagens com erro hoje | Mensagens registradas com erro de processamento. | Hoje |
| Mensagens pendentes hoje | Mensagens registradas como pendentes. | Hoje |
| Mensagens processadas hoje | Mensagens preparadas ou registradas como processadas no ambiente atual. | Hoje |

Use esse card para identificar falhas ou pendências que possam afetar confirmações, lembretes e comunicação com clientes.

No ambiente atual, interprete esses números como acompanhamento operacional das mensagens registradas pelo sistema, não como garantia de entrega final ao celular do cliente.

## 12. Eventos do WhatsApp

A lista **Eventos** agrupa comunicacoes e ocorrencias por tipo.

Eventos atualmente tratados em linguagem funcional:

| Evento | O que significa |
| --- | --- |
| Lembrete registrado ao cliente | Um lembrete do atendimento foi registrado para o cliente. |
| Agendamento confirmado | O atendimento foi confirmado. |
| Atendimento concluido | O atendimento foi finalizado. |
| Aguardando confirmação do estabelecimento | O atendimento precisa de confirmação operacional. |
| Novo agendamento realizado | Um novo atendimento foi registrado. |
| Lembrete registrado ao estabelecimento | Um alerta operacional foi registrado para acompanhamento do atendimento. |
| Agendamento cancelado | O atendimento foi cancelado. |
| Cliente não compareceu | Foi registrado que o cliente não compareceu. |
| Agendamento remarcado | O atendimento recebeu novo horario. |

## 13. Servicos

O card **Servicos** mostra um ranking do mes atual com base no historico de atendimentos.

| Lista | O que mostra | Como usar |
| --- | --- | --- |
| Mais realizados | Servicos concluidos com maior quantidade no mes. | Identificar os servicos com maior procura. |
| Receita por servico | Soma dos valores dos servicos concluidos no mes. | Entender quais servicos mais contribuem para a receita do periodo. |

Quando nao houver dados, aparece **Sem dados para o periodo.**

## 14. Profissionais

O card **Profissionais** mostra ocupacao e ocorrencias do mes atual.

| Lista | O que mostra | Como usar |
| --- | --- | --- |
| Maior ocupacao | Profissionais com mais atendimentos concluidos no mes. | Acompanhar distribuicao de demanda. |
| Clientes que não compareceram por profissional | Quantidade de clientes que não compareceram ligada a cada profissional. | Identificar onde pode ser necessário reforçar confirmações. |

Quando nao houver dados, aparece **Sem dados para o periodo.**

## 15. Atividades recentes

O card **Atividades recentes** mostra eventos que ja ocorreram no estabelecimento ou na conta.

Ele pode exibir registros como novo agendamento, confirmacao, conclusao, cancelamento, lembretes enviados e atualizacoes operacionais.

Diferença importante:

| Card | Foco |
| --- | --- |
| Pendencias importantes | Algo pode exigir acao. |
| Atividades recentes | Algo ja aconteceu e ficou registrado. |
| Proximos atendimentos | O que esta perto de acontecer. |
| Agenda do dia | Visao organizada do dia. |

## 16. O que consultar primeiro

Ordem recomendada para iniciar o dia:

1. **Pendencias importantes**: veja se algo exige acao imediata.
2. **Proximos atendimentos**: acompanhe os horarios mais proximos.
3. **Agenda do dia**: entenda o fluxo completo do dia.
4. **Visao operacional**: confira confirmacoes, andamento, cancelamentos e ocupacao.
5. **WhatsApp operacional**: veja se ha falhas ou pendencias de comunicacao.
6. **Clientes e agenda**: acompanhe clientes atendidos, novos, recorrentes e status.
7. **Servicos**: veja o movimento do mes.
8. **Profissionais**: acompanhe ocupação e clientes que não compareceram.
9. **Atividades recentes**: revise o que ja aconteceu.

## 17. Situacoes comuns

| Quando acontecer | O que fazer |
| --- | --- |
| Ha uma pendencia importante | Leia a mensagem e acesse a area indicada pelo alerta, quando ele for clicavel. |
| Ha atendimento aguardando confirmacao | Acesse a agenda e revise o atendimento. |
| Ha erro de WhatsApp | Consulte a area de comunicacao/campanhas e verifique os envios. |
| A agenda esta com baixa ocupacao | Verifique oportunidades de novos agendamentos ou encaixes. |
| Nao ha proximos atendimentos | Use **Novo agendamento** se houver demanda para cadastrar. |
| O trial esta perto do fim | Revise o plano e antecipe a regularizacao. |

## 18. Exemplo pratico

Ao abrir o Dashboard, o usuario encontra:

- Nenhuma pendencia importante.
- Dois agendamentos hoje.
- Um atendimento concluido.
- Um atendimento aguardando cliente.
- Ocupacao de 25%.
- Nenhum erro de WhatsApp.

Isso indica que a operacao esta sem alerta critico no momento, mas ainda existe atendimento para acompanhar. A ocupacao de 25% sugere que ha espaco para novos horarios no dia. Como nao ha erro de WhatsApp, as comunicacoes registradas nao apresentam falha destacada.

## 21. Divergências funcionais corrigidas

| Divergência tratada | Como ficou para o usuário |
| --- | --- |
| Textos com acentuação incorreta | Os componentes principais do Dashboard foram revisados para português do Brasil. |
| Status técnicos na agenda | A lista passou a exibir descrições funcionais, como **Aguardando confirmação do cliente**. |
| Botões em estado vazio sem destino | O botão **Novo agendamento** direciona para a criação de agendamento. |
| Busca sem função operacional | O campo aparece desabilitado como **Busca em desenvolvimento**. |
| Ambiguidade no WhatsApp operacional | O card usa termos como **Mensagens processadas hoje**, sem prometer entrega final ao WhatsApp. |
| Ajuda pouco evidente | Os indicadores mantêm descrições curtas e ajudas funcionais por card. |
